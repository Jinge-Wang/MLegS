# tatsu-original

Matsushima's original serial code (`legops.f90`, `lin_legendre.f90`,
`march.f90`, ...) -- historical reference for the basis and operators
(recurrences for `1/r`, `r*d/dr`, Laplacian/Helmholtz inverses).

(Provenance text taken from `PROJECT_DEFINITION.md` section 2.2 of the
Pseudo-SpeX repository, where this code was kept at
`solvers/tatsu-original/`.)

This is an orphan branch of `github.com/Jinge-Wang/MLegS`: it shares no
commit history with `main`, `boussinesq`, or any other branch of this
repository. It exists to consolidate this reference material as part of
the owner's own MLegS repository rather than leaving it unversioned on
local disk.
